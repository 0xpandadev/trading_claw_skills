# Trading Claw Skills 詳細ガイド（日本語）

各SKILLの「紹介」「使い方」「効果」を一覧で確認したい場合は、以下を参照してください。

- [Full Skill Guide (English)](SKILL_GUIDE.md)

## 使い方

1. まず対象SKILLを選ぶ（例: `tenbagger-screener`）
2. 一覧の `When to use` で適用場面を確認する
3. `How to use (inputs)` に沿って入力条件を明示する
4. `Expected effect` を見て、出力の活用方法を決める

## 補足

- 全54スキルを網羅
- 実運用向けに「入力条件」と「期待アウトカム」を明示
- 新規スキル追加時も同じ形式で拡張可能
